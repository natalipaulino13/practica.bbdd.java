# 📚 Biblioteca — Java + JDBC + SQLite

Aplicación desarrollada en Java para gestionar una biblioteca mediante una base de datos SQLite utilizando JDBC.

El programa permite realizar operaciones CRUD sobre los libros, realizar búsquedas, aplicar filtros y ordenar los registros.

## 🎯 Objetivo de la práctica

El objetivo es desarrollar una aplicación de gestión de biblioteca conectada a una base de datos SQLite.

La aplicación permite administrar los libros almacenados y trabajar con diferentes operaciones sobre la información:

- Añadir libros
- Consultar libros
- Buscar libros
- Actualizar información
- Eliminar registros
- Filtrar libros disponibles
- Realizar búsquedas avanzadas
- Ordenar los resultados
